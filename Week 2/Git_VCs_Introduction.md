#Introduction to Git and Version Control

##What is version control?

Version control is a way of saving every version of your work as you go, so if something breaks or you change your mind, you can go back to an earlier one.

##Git Commands
pwd - present working directory
cd - change directory
ls - shows whats inside that direcrory 
git status - check if its a repo
git init - creates a new git repository 
git add ... - add a single file to stage
git add . - adds everything in the current directory
git commit - m ".." - commit staged files with a message.
